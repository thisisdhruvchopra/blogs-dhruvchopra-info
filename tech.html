The timeline

~2002

First encounter with a PC — nursery school

Dad's computer. Windows 98 or XP, probably. I have no clear memory of the machine. I have a very clear memory of how it felt to use it.

~2008

Built my own PC at age 10

Not a kit. Actual parts sourced, assembled, BIOS configured. It posted first try. Still one of the most satisfying moments of my life.

2010s

Heavy gaming era

The years I spent understanding hardware through the lens of frame rates. Games taught me more about performance optimisation than any textbook.

2016

Started programming in Java

The language I still reach for when I want to think clearly about a problem. There's a stubbornness to Java that suits me.

2024

DevOps, cloud, Kubernetes at C3iHub

Infrastructure as code, CI/CD, container orchestration. The operational layer of systems has become as interesting to me as the software itself.

Now

Watching AI reshape everything

From the position of someone who has been in this field long enough to remember when "machine learning" was a niche academic topic. The pace is genuinely disorienting.

Things I genuinely love

🖥️ Retro computing The era when constraints forced creativity. Demoscene. Amiga. The aesthetic of early UIs.
🐍 Python The language I learned last but use most. Fast to think in.
☕ Java Verbose, opinionated, and still my anchor. Programming since 2016.
🐳 Docker + K8s The operational layer becoming as interesting as the code layer.
🕸️ The internet itself Still astonishing that it works. Still thinking about what it's doing to us.
🤖 AI / ML Genuinely the most disorienting technological moment I've been alive for.
🔐 Security Where I professionally live. Deception systems, threat intelligence, honeycraft.
📟 Command line The terminal is still the most honest interface ever built. Nothing hides.

Opinions I hold

stdout

The retro computing era produced more interesting aesthetics than anything since. When you have 16 colours and 8-bit audio, every decision is a statement.

AI will not replace programmers. It will replace programmers who treat programming as typing.

Most software is too complicated. The interesting problems are almost always constraint problems, not feature problems.

Building your own PC at age 10 should probably be a requirement for anyone who wants to talk seriously about hardware performance.

The terminal is not a legacy interface. It is the interface everything else is pretending to replace.
